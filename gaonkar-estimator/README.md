# Gaonkar Cost Estimator (source app)

Reference app for Gaonkar Builders & Architects / Gaonkar Interior Factory / Astro uPVC.

- `index.html` – the complete, self-contained app (all CSS, JS, rates and photos embedded). Open it in a browser to see it.
- `ads/` – three promo images used by the app.

Screens: Home, Division pages (Builders / Interior / uPVC), Design Gallery, Materials, Estimate (construction, modular interior, uPVC windows), Request a Quote (WhatsApp), Vastu Layout, Assistant, Saved.
